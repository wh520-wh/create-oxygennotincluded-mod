# 建筑与房间

## 定义及生命周期

检查 IBuildingConfig 的 BuildingDef、ConfigureBuildingTemplate、预览/施工/完成配置和运行组件。核对尺寸、BuildLocationRule、支撑、翻转、朝向、碰撞、选中、占地、场景层、材质类别/质量、施工技能时间、熔点过热、拆除和剩余库存。预览、待建与完成是独立视觉状态：对照原版确认各自的动画、符号与渲染机制，蓝图不得复用成品图层，建造前后保持占地、原点、缩放与地板基线一致；建造阶段美术的完整要求见美术与动画文件。

独立审查预览与实际完成建筑，检查原生模板自动添加了什么，避免重复添加相互争用的控制器。若自有状态机负责动画/active，不再盲加第二个 PoweredActiveController；但必须补齐它原本承担的功能。

## 电力、配方和流量

分别配置消费者/发电机的额定功率、容量、接口、运行状态与模拟调用。用目标版本 Generator/EnergyGenerator 原生行为承接电网与属性；确认调优后的实际 WattageRating，而不是永远写死额定瓦数。

列出输入、输出、催化剂、运行耗材和副产物的 kg/s；区分 kW、kJ、kDTU/s 与每周期。记录质量、能量、热量的模型取舍和闭环累积。不要把建造用钢误当运行钢耗，也不要因为比较忽略耗电而取消实际耗电。

执行处理前检查：Operational/自动化、全部原料、出口可用、缓冲容量、电网/供电、环境条件；消费与产出应协调，不能先耗料后发现出口满。部分 dt 或部分燃料按比例处理；考虑吞吐精度、库存变更和异常中途失败。

## 管口和物流

配置正确 ConduitType、CellOffset、输入 capacityTag、错误介质处理、消费速率、内部存储和输出过滤。对断管、堵塞、错误元素和两台机器连成回路分别测试。明确端口流量与配方流量区别，避免缓冲吸入被误当加工速度。

固体补给检查 ManualDeliveryKG/原生等价、RequestedItemTag、refillMass、storage、优先级、chore 和自动清扫器；检查运输入口、搬运条件与容量。补给任务不可达时给玩家可见原因。

## 发电厂与调优

“电网发电”“房间分类”“可调优”是三个独立维度，逐项验收。

对照目标版本原版同类发电机审查 RoomConstraints.ConstraintTags.PowerBuilding、GeneratorType、HeavyDutyGeneratorType/LightDutyGeneratorType、IndustrialMachinery 及房间约束。只添加适用标签，不把耗电反应器标成发电设备来凑房间。

检查 Tinkerable.MakePowerTinkerable 或当前版本等价机制、实际调优属性、芯片材料、工程师技能、工作站导航/位置、chore、动画和完成后的持续时间。缺标签会影响房间，补标签仍不证明调优动作可完成。

添加 Tinkerable、显示调优标记或出现“工程师的调校”状态，都不能单独证明发电增益已接通。实际发电计算必须使用原生增益作用后的属性：不要始终读取固定基础功率，也不要在原生机制已计算增益后再次乘倍数，造成重复加成。

验收：合法封闭房间与面积 → 房间覆盖层识别 → 电控站可工作 → 小人制作芯片 → 工程师到达工作位置 → 完成调优 → 效果添加 → 发电属性变化 → 实际产电变化 → 效果到期恢复 → 保存读取。保持供料、出料和运行条件一致，比较调优前后相同实际运行时间内的累计产电量，并核对燃料消耗是否符合设计；同步检查动态卡片显示。去掉关键建筑/打开房间测试失效反馈。房间不认时核对冲突工业建筑及边界，不直接重写房间规则。尚未完成实际测量时，标记“调优实际增益待验证”。

## 玩家反馈与环境

为停机原因显示状态：缺料、缺电、出口堵塞、关闭、过热、淹没、不可达。保持多个条件的反馈优先级合理；不只在日志里打印玩家看不到的信息。

说明与实际端口、容量、功率、热量、配方一致；使用原生单位和温度换算。检查装饰、噪声、辐射、光照、声音、可修理、拆除返还与材料温度加成。新建筑的工业或装饰分类必须反映真实用途。

## 卡片与界面信息

新增建筑不能只提供名称、描述和建造菜单说明。对照同类原版建筑，检查鼠标悬浮卡片、选中面板、效果栏、电路列表及相关覆盖层的信息；发电建筑应提供适用的功率、产热、温度、运行状态和增益信息。核对原版使用的状态项、描述接口和动态数据来源，避免建筑实际具备功能、卡片却漏掉对应信息。

区分四种数值口径：基础额定功率、当前有效功率、实际产电和电路负载。固定说明明确表示基础值，动态信息读取运行时属性。不用写死的数字冒充实时结果，也不因为固定效果栏没有变化就认定调优失效——先确认该信息应来自固定说明还是动态来源。

验收：建造并选中建筑，逐项核对悬浮卡片、选中面板、效果栏、电路列表与覆盖层；与同类原版建筑并排比较信息项与单位；确认动态数值随运行状态变化（填充燃料、接入电网、触发调优），停产、缺料、过热时显示对应状态；保存读取后信息仍正确。
