# 系统关联思路

按内容和改动范围判断适用关联。这里是提醒，不是要求每次填完所有行；不适用的系统可以跳过，重要但不确定的关联继续查。新机制从原版相邻对象和完整生命周期推导，不能以清单未列出为理由遗漏。

## 想到哪些方面

- 身份与发现：独有稳定ID、Tag、元素/实体对应、研究、菜单、沙盒及百科。
- 获得与建造：来源、配方、建材选择、支撑、尺寸、技能、施工、蓝图和升级。
- 物流与存储：环境元素、瓶罐、碎块、种子/蛋、拾取、搬运、清扫器、储存、筛选与释放。
- 使用与转换：原料、催化剂、速率、质量、温度、病菌、产物、热量及错误输入。
- 电力与自动化：接线、功率、容量、蓄电池、调优、红绿信号、暂停与停机。
- 管网：液气固层、端口位置、吞吐、缓冲、断开、堵塞、错介质及相变。
- 房间与小人：用途标签、房间限制、任务优先级、技能、路径、工作位置和补给。
- 环境与生命：温度、压力、淹没、真空、导热、光照、辐射、噪声、装饰、疾病、成长与死亡。
- 信息与外观：悬浮卡片、选中面板、基础/动态参数、状态、覆盖层、图标、动画、特效与声音。
- 保存与世界：存读、拆除、相变、跨世界、DLC、升级与卸载依赖。
- 共存与交付：补丁范围、原版行为、其他Mod、性能、实际运行资源、源文件和安装方式。

对输入问“从哪里来、谁运来、放在哪里”；对输出问“如何显示、谁使用、堵了怎么办”；对状态问“谁触发、谁看到、谁保存、如何恢复”。

## 用生命周期发现遗漏

- 新液体：环境物质 → 擦拭成瓶 → 搬运/储存 → 装桶/倒出 → 过滤与消费 → 相变/存读。
- 新材料：格子纹理 → 挖掘碎块 → 质量分档外观 → 搬运/储存 → 加工/相变 → 读档。
- 新建筑：研究/建材 → 放置与施工 → 端口/补给 → 加工 → 异常提示 → 拆除与库存。
- 新植物：种子 → 种植约束 → 灌溉施肥 → 生长/休眠/枯萎 → 收获与产物用途 → 拔除/读档。
- 新动物：蛋 → 幼体/成体 → 饮食排泄 → 导航/搬运/牧场 → 繁殖/死亡 → 读档。
- 新装备：制作 → 储存 → 穿戴与装备站 → 属性/消耗/导航 → 损坏或卸下 → 读档。

同一身份的环境、地面物品、UI资源和配方标签是不同表现，一处存在不代表其他处自动补齐。局部修复顺着共用代码和这些关系判断影响范围，避免重新审查无关系统。
