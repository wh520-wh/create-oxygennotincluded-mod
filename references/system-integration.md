## 沿交互发现遗漏

对每种输入问“从哪里来、如何选中、由谁运来、放在哪里”；对每种输出问“如何显示、装在哪里、谁能利用、堵了怎么办”；对每种状态问“谁触发、谁看到、谁保存、谁恢复”。

检查同一身份的多种表现：环境元素 ≠ 搬运实体 ≠ 界面资源 ≠ 配方标签。某一层有对象不等于其他层会自动补齐。

区分合法状态与可见几何：非实体建筑所占格子可以仍含气体，镂空也可以露出背景。不要为了视觉贴合把整座机器的格子变成实心砖。校准底座、轮廓和占地规则，而不是阻塞流体模拟。

## 跨类型例子

- 新液体：三态（若设计适用）→ 瓶装 → 擦拭 → 搬运 → 装桶/倒液体 → 储存/过滤 → 环境释放 → 保存读回。
- 新加工建筑：建材与解锁 → 补给和端口 → 配方 → 输入温度疾病 → 输出/副产物 → 堵塞/过热 → 拆除库存。
- 新植物：种子物品 → 种植约束 → 灌溉施肥 → 生长/枯萎 → 收获产物 → 食谱/储存 → 拔除返还与读档。
- 新动物：蛋 → 孵化 → 幼体成体 → 饮食排泄 → 导航/抓捕搬运 → 牧场与幸福 → 繁殖死亡 → 存档。
- 新装备：制作/研究 → 库存 → 装备站和小人穿戴 → 属性/消耗 → 导航与工作动画 → 损坏/卸下 → 读取。
- 新材料（如冰类）：菜单图标 → 环境格子外观 → 挖掘碎块/掉落物 → 搬运/储存/融化或相变 → 释放 → 保存读回；各显示链分别验收。

对没列到的新机制，继续从原版相邻对象和生命周期推导，不以清单没有这一项为理由跳过。
