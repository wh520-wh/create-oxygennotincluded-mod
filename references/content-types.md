# 其他内容类型

按主文件的系统关联思路展开适用类型。下列是审查方向，实际 API 与适用规则必须查目标版原生相邻对象。

## 食物、药品与工业产品

确认配方、制作站、原料与产物实体、质量或份数、热量/营养、保鲜/腐败、可储存和食用、口粮权限、烹饪升级、过敏/疾病、士气与动画；药品检查病症适用、治疗作用、使用 chore 和效果持续。工业品检查制造研究、运输、材料标签与其他配方意外消费。非易腐物品不要盲加腐败。

## 植物

补齐种子物品及种植动作、地面/盆/砖/水培约束、温度压力气体、光照、灌溉施肥、疾病、成熟/枯萎/休眠、家养野生差异、收获工作与产量、拔除掉种、资源词条及生命周期动画。检查路径、农场房间、农业技能/肥料增益、存读状态，确保产物自己也走物品审查。

## 动物

设计物种标签、成人/幼体/蛋、寿命、孵化繁殖、饮食排泄、摄食可达性、驯化幸福、过密/拥挤、导航方式、栖息地、牧场互动/梳毛、搬运站/抓捕/放生、战斗/死亡掉落、叫声与符号。验证野生及驯养、跨世界转移和读档。不要只实现一个会动的 sprite。

## 疾病与状态效果

定义病菌在介质上的生长死亡、传播路径、感染条件、免疫、症状、治疗与恢复、UI/覆盖层、存档；区分物质携带病菌与小人患病。属性增益检查堆叠、过期、移除、存读和其他 Mod 同类属性。不要用未经设计的全球病菌改写影响全殖民地。

## 小人、技能和装备

新增特质/技能查岗位与技能树、前置、士气、属性显示、行为和存档身份。装备补齐制作/回收、穿戴许可、装备站、耗氧/电池/燃料、耐久修理、适配身体与互动动画、取下掉落、导航限制与小人死亡返还。装饰换肤检查 facade、解锁、符号覆盖及所有适用状态。

## 自动化、运输、门和砖

明确红绿信号含义、失去供电时行为、输出更新频率、保存恢复、带状信号通道和端口方向。传感器查阈值单位、滞回和假信号。运输查容量、取放、任务与堵塞。门/砖查占格、支撑、温度导热、透光、流体阻挡、导航、开闭/锁定、权限、角连接、修理及替换建造。

## 火箭、太空与多个世界

核对 DLC 可用性、模块顺序/限制、连接和建造规则、舱内与舱外世界、燃料氧化剂、质量/高度、发射航程、着陆、星图交互、钻探货物、导航/小人可达、声音特效、状态和存档。不要在基础版初始化时访问不存在的 DLC 对象。跨世界处理检查世界 ID、已加载世界集合与销毁顺序。

## 喷泉、地形、遗迹与世界生成

检查出生规则、种子可复现性、biome/噪声/模板、边界、温度质量、喷发/休眠分析、建筑埋藏、奖励解锁、研究和词条。区分新世界生成与旧存档修改；用户未授权时不偷偷改已有世界。世界模板、坐标及 DLC 路径按目标版本校验。

## 房间、配方和全局改造

新增房间检查尺寸/优先级、必须与禁止建筑、标签、房间重算、buff、覆盖层和其他房间冲突。新增配方检查双方物品注册、可发现性、批次、配方过滤、温度/疾病、稳定 recipe ID 和保存订单。

必须改全局系统时明确：被改方法、对象范围、原版保证、失败行为、共存策略和回归场景。禁止宽泛异常吞噬或最高优先级争抢替代设计。批量改行为要测原版对象和其他 Mod 对象不受无关影响。
